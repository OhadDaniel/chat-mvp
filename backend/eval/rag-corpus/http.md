# HTTP basics

## Status codes

HTTP status codes tell the client what happened with a request. A 200 status
means OK — the request succeeded. A 404 status means Not Found — the server
could not find the requested resource. A 500 status means Internal Server
Error — something went wrong on the server.

## Methods

HTTP methods describe the action. GET retrieves data, POST creates a new
resource, PUT updates an existing resource, and DELETE removes one.
